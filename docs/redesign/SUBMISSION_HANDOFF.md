# Designathon Submission Handoff Checklist

The contest requires a single original main concept, title, 100–200 word concept explanation, final design/prototype link and screenshots or PDF export, originality declaration, and disclosure of material AI/third-party asset use. The repository must be public with source code and documentation; a live demo is mandatory. Verify final event dates and submission fields on the official contest page.

Before submission:
- [ ] One clear title and central creative idea.
- [ ] Working public live demo.
- [ ] Public Git repository with source and README.
- [ ] Screenshots of desktop and mobile experience.
- [ ] 100–200 word concept explanation.
- [ ] Originality declaration.
- [ ] AI-use disclosure where applicable.
- [ ] Third-party asset/font/model credits and licences.
- [ ] Confirm all files and links open without private access.
- [ ] Keep editable source, design files, version history and evidence of authorship.

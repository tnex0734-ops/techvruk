# Project Brief — Taushik Personal Portfolio Redesign

## Status
Creative direction agreed; repository audit and workspace preparation approved. Technical decisions baseline finalized in `docs/ANTIGRAVITY_WORKSPACE_PREPARATION.md`.

## Owner and positioning
The owner wants to present himself as a **self-taught product designer and product builder**. Preserve the exact, verified professional positioning and supporting details already published in the existing portfolio. Do not invent credentials or outcomes.

## Goal
Transform the existing portfolio into a memorable, professional digital experience that demonstrates product design, visual craft and the ability to bring digital products to life. It must remain useful to recruiters, collaborators, clients and designathon judges.

## Primary creative idea
A personal portfolio that pairs two distinct but coherent experiences:

1. **The room:** A realistic, carefully art-directed 3D interpretation of the owner's actual bedroom/workspace. It serves as the homepage/hero and as an optional discovery/navigation environment.
2. **The About composition:** A typographic artwork on a white background, using red flowing ribbons/waves with the biography following their curves. This is an SVG-led editorial composition, not a 3D scene.

The room should feel tactile, calm, personal and believable. The About section should feel expressive, typographic and graphic. The common thread is a precise white/red identity and editorial typography.

## Required room arrangement
- Left side: cupboards.
- Corner: laptop workstation with laptop stand, keyboard, mouse, fishbowl, hanging quote cards and a plant.
- Right side: door, window and bed.

This arrangement is supplied by the owner. Exact measurements, room photographs, furniture dimensions, wall colour, flooring and lighting conditions are not yet supplied. Do not invent those as facts. Establish a proportionate art-directed interpretation, and request/accept reference photographs when available.

## Portfolio sections to prioritise
1. Homepage/hero: 3D room scene and conventional accessible navigation.
2. About: flowing red SVG ribbons and curved biography typography.
3. Selected work: editorial, image-led project index with real case-study links.
4. Experience and achievements: concise archive/timeline using verified content.
5. Contact: direct contact details and working links; the room door can act as a visual metaphor or optional entry point.

Individual case-study content should be preserved and redesigned selectively. Do not rebuild all case studies at once unless the audit shows a clear need.

## Designathon relevance
The entry should be a single coherent main concept, not a collection of unrelated visual experiments. The design should demonstrate originality, visual impact, craft, storytelling and audience relevance. The portfolio remains a real professional tool; usability and truthful content take priority over spectacle.

## Deliverables
- A working responsive website.
- Existing project content and links preserved.
- Source code in the existing repository.
- A public Git repository with readable documentation and asset credits.
- A deployed, publicly viewable live demo.
- Screenshots/process evidence suitable for a designathon submission.

## Constraints
- Build on the existing repository.
- Do not assume the current framework until audited.
- Do not install a new stack before the audit.
- Preserve deployment configuration unless changes are necessary and reviewed.
- Do not commit secrets or generated build artefacts.
- Respect reduced motion, keyboard navigation, touch input and WebGL fallback.
